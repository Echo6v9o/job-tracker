# 🎯 秋招投递管理看板

一个纯本地、零依赖的秋招 / 校招投递记录与进度管理工具。单个 HTML 文件，双击即用；可选配置 GitHub 私有仓库云同步，手机、电脑多端实时同步。

## ✨ 功能

- **投递记录**：公司、岗位、岗位类型、城市、投递渠道、薪资、投递链接、备注、⭐重点关注置顶
- **状态自由流转**：已投递 / 测评 / 笔试 / 一面 / 二面 / 三面 / HR面 / Offer / 已挂 / 已放弃——测评与笔试可有可无、先后不限，下拉自由切换
- **进度时间线**：每次状态变更自动记录时间，展开即看完整流程
- **双视图**：列表（搜索 / 多维筛选 / 排序 / 分页）+ 看板（按状态分列、拖拽改状态、列内滚动与折叠）
- **统计仪表盘**：转化漏斗、状态分布、近 14 天投递趋势、总投递 / 面试中 / Offer 等关键指标
- **近期安排提醒**：自动汇总未来笔试 / 面试时间，临近标红
- **自动挂起**：流程超过 15 天无进展且无后续安排的记录自动标记已挂（可改回）
- **公司速查**：搜索框输入公司名即时弹层显示投递状态；添加投递时自动提示已投过的岗位，防重复投递
- **数据管理**：导出 / 导入 JSON 备份，导出 CSV（Excel 可直接打开）
- **可选云同步**：数据存放在你自己的 GitHub 私有仓库，不经过任何第三方服务器

## 🚀 快速开始

### 方式一：本地使用（最简单）

下载本仓库的 `index.html`，双击用浏览器打开即可。数据自动保存在浏览器本地（localStorage）。

### 方式二：部署在线版（手机也能用）

1. Fork 或新建一个**公开**仓库，放入 `index.html`
2. 仓库 `Settings → Pages`：Source 选 `Deploy from a branch`，分支选 `main`、目录 `/ (root)`，保存
3. 等待一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`
4. 手机浏览器打开同一地址，可「添加到主屏幕」当 App 使用

本地双击打开与在线版数据可以互通（见下方云同步）。

## ☁️ 配置云同步（多端同步）

数据是一个 `data.json`，存放在**你自己的私有仓库**中，页面通过 GitHub API 读写，令牌只保存在你自己设备的浏览器里，不会出现在代码或链接中。

**第一步：建数据仓库**

在 GitHub 新建一个**私有**仓库（如 `job-tracker-data`），里面什么都不用放。

**第二步：生成令牌（Fine-grained Token）**

1. GitHub 右上角头像 → `Settings` → 左侧最底 `Developer settings` → `Fine-grained tokens` → `Generate new token`
2. 名称随意（如 `job-tracker`），`Expiration` 选长一些（如 1 年）
3. `Repository access` 选 `Only select repositories` → 选中刚才那个私有数据仓库
4. `Permissions → Repository permissions → Contents` 设为 `Read and write`（其余保持默认）
5. 生成后复制以 `github_pat_` 开头的令牌（只显示一次）

**第三步：页面配置**

打开页面 → 工具栏点 **☁️** → 填入 GitHub 用户名、数据仓库名、令牌 → 点「测试连接」确认 ✅ → 保存。

之后每次修改都会自动同步（防抖合并，约 1.5 秒内连续操作只产生一次提交）；在另一台设备打开同一页面会自动拉取最新数据，切回页面时也会自动同步其他设备的修改。

## 🔒 数据与安全

- 未配置云同步时：数据仅存于本机浏览器 localStorage，清除浏览器缓存前请先「📤 导出」备份
- 配置云同步后：数据存于你的私有仓库，每次保存自动生成 git 提交，**误删可从仓库历史恢复**
- 令牌权限最小化：只授权一个私有仓库、只有 Contents 读写权限，即使泄露影响面也只是这一个数据文件
- 本工具无后端、无统计、无广告，全部代码就在一个 HTML 文件里，可自行审计
